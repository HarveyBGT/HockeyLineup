# Fortress

A native iPhone app for building and sharing field-hockey lineup graphics — pick a fixture or
formation, build your squad, place players on the pitch, toggle home/away kit colours, and share
the finished graphic anywhere (WhatsApp, Instagram, AirDrop, Photos...).

Named after Dukes Meadow, Barnes Hockey Club's home pitch — known to players and supporters as
"the Fortress." Built for Barnes HC, but works for any club — nothing is hardcoded to one team.

## What's here

- SwiftUI, iOS 17+, no backend, no accounts, no third-party dependencies.
- Adopts iOS 26's Liquid Glass design system where available (badges, prominent buttons), with
  graceful fallbacks so it still looks right back to iOS 17.
- Lineups and the player squad are saved locally on-device as JSON
  (`Documents/lineups.json`, `Documents/players.json`), decoded field-by-field with defaults so
  adding a new field to a model later never resets a user's existing saved data.
- Sharing exports a JPEG via the system share sheet — sized and compressed for chat apps like
  WhatsApp, no server involved.
- Project file (`HockeyLineup.xcodeproj`) is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)
  from `project.yml`, so the `.xcodeproj` itself isn't hand-edited or committed to fight merge conflicts —
  regenerate it any time with `./Scripts/generate_project.sh` (**not** a bare `xcodegen generate` — see
  that script for why).

## Features

- **8 formations**: 5-3-2, 4-4-2, 4-3-3, 3-4-3, 3-5-2, 4-2-4, 2-3-5, and 4-4-2 Diamond.
- **Player squad database**: first/last name, squad number, goalkeeper flag, captain/vice-captain,
  and a procedurally-generated avatar (skin tone, hair style/colour, glasses) — no photo upload
  needed. Create players inline while building a lineup, or manage the whole squad (edit/delete)
  from the Squad screen.
- **Fixtures**: pick from Barnes M3's full 22-round 2026-2027 season (every match in their
  division, scraped from the England Hockey site) to auto-fill opposition, date/time, home/away,
  and pitch — or fill those in by hand for any other match.
- **Bench & officials**: up to 5 named bench players, a coach, and two umpires — all included on
  the shared graphic alongside the fixture summary.
- **Home/away kit toggle**: set separate home and away kit colours per lineup; the player icons'
  shoulders re-colour to match whichever is active.
- **Real pitch venues**: pick from 20 real London & South-East England hockey clubs' home pitches
  (Barnes HC's Dukes Meadow, Surbiton, Southgate, and more) or a generic classic-green pitch, each
  with a stylised flat crest and its own pitch background colour.
- Drag players between positions, tap an empty slot to assign someone.

## Getting started

1. Install Xcode.
2. Install XcodeGen if it's not already on your machine: `brew install xcodegen`
3. Install the `xcodeproj` gem if it's not already on your machine: `gem install xcodeproj`
4. From this folder: `./Scripts/generate_project.sh`
5. Open `HockeyLineup.xcodeproj` in Xcode.
6. Select the `HockeyLineup` scheme, pick an iPhone simulator, and hit Run (⌘R).

## Before you can run on a real device or submit to the App Store

- **Bundle identifier**: currently `com.example.hockeylineup` in `project.yml`. Change it to something
  you own (e.g. `com.yourname.hockeylineup`), then re-run `./Scripts/generate_project.sh`.
- **Signing team**: in Xcode → target → Signing & Capabilities, select your Apple Developer team.
  You'll need an Apple Developer Program membership ($99/yr) to submit to the App Store (a free
  personal-team signing is enough to run on your own device for testing).
- **App icon**: `Resources/Assets.xcassets/AppIcon.appiconset/icon-1024.png` is a flat navy/gold
  crenellated shield mark (the "Fortress" crest) — swap it for your own 1024×1024 design if you
  fork this for another club.
- **App name / display name**: the home-screen name ("Fortress") is set via `CFBundleDisplayName`
  under `targets.HockeyLineup.info.properties` in `project.yml`; the Xcode project/scheme name and
  bundle identifier are unchanged (`HockeyLineup` / `com.example.hockeylineup`).

## How it works

- `Sources/Models/Formation.swift` — formation presets, each a list of normalized (0...1) pitch
  positions tagged GK/DEF/MID/FWD.
- `Sources/Models/LineupCard.swift` — one saved lineup: opposition, match date/time, home/away
  flag and kit colours, formation, assigned player IDs, and pitch venue (auto-filled from a
  fixture, or set by hand).
- `Sources/Models/Player.swift` / `PlayerAvatar.swift` — a squad member and their avatar traits.
- `Sources/Models/PitchVenue.swift` — the catalogue of real club home pitches, each with a
  stylised `ClubCrest`.
- `Sources/Models/LeagueData.swift` — seeded team/fixture data for Barnes M3's division.
- `Sources/Persistence/LineupStore.swift` / `PlayerStore.swift` — load/save lineups and the squad
  as JSON in the app's Documents folder.
- `Sources/Views/PitchMarkingsView.swift` — draws the pitch (boundary, halfway line, 23m lines,
  shooting circles, goals) with `Canvas`.
- `Sources/Views/PitchView.swift` — overlays draggable/tappable player position dots on the pitch.
  Tap a dot to open the player picker; drag one filled dot onto another to swap the two players.
- `Sources/Views/PlayerAvatarView.swift` — renders a player's procedural avatar.
- `Sources/Views/PlayerFormView.swift` / `PlayerPickerView.swift` / `PlayerDatabaseView.swift` —
  create/edit a player, assign one to a pitch position, and manage the full squad.
- `Sources/Views/PitchVenuePickerView.swift` — choose a real club home pitch for a lineup.
- `Sources/Views/ExportCardView.swift` — a plain (non-interactive) styled version of the lineup,
  rendered off-screen to a JPEG via `ImageRenderer` when you tap Share.
- `Sources/Views/ContentView.swift`, `FormationPickerView.swift`, `LineupEditorView.swift` — the
  main screens: saved lineups list → pick a formation → edit & share.

## Testing

`Tests/HockeyLineupTests` is a Swift Testing (not XCTest) suite covering the model layer:
formations, lineup card logic, the resilient JSON decoding, the fixture database's round-robin
structure, and crest resolution. Run it with `xcodebuild test -scheme HockeyLineup` or ⌘U in
Xcode.

## iCloud sync

Lineups and the squad sync across your devices via CloudKit (private database, best-effort —
local JSON stays the source of truth, sync just keeps other devices on the same iCloud account
up to date). New/changed records push after every save; each store pulls and merges remote
changes once at launch, newest `updatedAt` wins per record.

**One-time setup required**: the iCloud container (`iCloud.com.example.hockeylineup`) needs to be
provisioned for this app's App ID, which has to be done in Xcode by a signed-in Apple ID — not
something that can be scripted. In Xcode: select the `HockeyLineup` target → **Signing &
Capabilities** → **+ Capability** → add **iCloud**, check **CloudKit**, and let Xcode create the
container. Until that's done, sync calls just fail silently (confirmed via `NoAccountExists`/
container errors that are caught, not thrown) and the app behaves exactly as it did before sync
existed — nothing breaks either way.

Deleting a lineup or player locally doesn't yet propagate as a deletion to other devices (only
creates/updates sync) — a deleted record with no further edits will keep reappearing until this
gets addressed.

## Known limitations

- Portrait only.
- Pitch venue colours are a stylistic default (blue), since real clubs don't publish their actual
  turf colour — Barnes HC's Dukes Meadow is confirmed blue; the rest are a best guess.
- Deletion isn't synced via iCloud yet (see above).
